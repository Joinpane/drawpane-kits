# Drawpane kits

The list of UI kits, libraries and templates that [Drawpane](https://github.com/Joinpane/drawpane) offers in its kit store. A Drawpane instance reads [`index.json`](index.json) and lets a team add any kit in one click: the file is downloaded from where it's hosted, checked, and imported into the team as a new file.

The registry holds two kinds of entry:

1. **Penpot's libraries and templates hub**, passed through as Penpot publishes it.
2. **Kits hosted here**, in `kits/<id>/`, under the licence rules below.

A Drawpane instance can point at its own copy of this index, or turn the store off (see Drawpane's `docs/self-hosting.md`).

## Penpot's hub

[Penpot's hub](https://penpot.app/penpothub/libraries-templates) is a source this registry reads, not one it curates. [`sources/penpot.json`](sources/penpot.json) is generated by [`scripts/penpot-hub.mjs`](scripts/penpot-hub.mjs) from Penpot's own data, every day by a [scheduled workflow](.github/workflows/penpot-hub.yml):

- every `.penpot` file in [penpot/penpot-files](https://github.com/penpot/penpot-files), with its size, its git blob SHA-1, and what kind of file it is, read from its first bytes (`container`: `zip` for Penpot's current format, `binfile-v1` for its older one, `lfs-pointer` for a file kept in Git LFS, which Pages doesn't serve);
- the `<name>.LICENSE` file beside it, where there is one, carried as Penpot provides it (its text and a link to it);
- from the hub's page for the file, where there is one: its title, author, description, categories, cover and dates;
- hub pages whose download isn't in that repository, as the hub lists them (without a file when the hub links to something that isn't one).

Nothing is renamed, edited, or left out. Files are never copied here: each entry points at Penpot's public hosting (`penpot.github.io/penpot-files`), where Drawpane downloads it when someone adds the kit, and checks it against the listed size and SHA-1. Covers are the hub's own.

**Licences.** Drawpane shows a Penpot entry's licence exactly as Penpot provides it: the LICENSE file's text and link when there is one, otherwise "Licence not stated by the author: see Penpot's hub" with a link to the entry's hub page. It credits the author and Penpot's hub as the source. Whether a kit can be used for a given purpose is between its user and its author; check the hub page and the file's own notes.

To change a Penpot entry, change it at Penpot (the hub or penpot-files). The next daily run picks it up.

## Kits hosted here

Kits converted or made for Drawpane (Material 3, Simple Design System, Carbon and others, coming) live in `kits/<id>/`:

```
kits/<id>/
  kit.json      what the kit is (schema/kit.schema.json)
  <file>.penpot the kit, unless kit.json points at an https URL
  cover.png     1390 x 724, rendered with Drawpane
```

`kit.json`:

| Field | What it is |
| --- | --- |
| `id` | The folder name: lower case and dashes, not starting with `penpot-`. |
| `name`, `description` | As shown in the store. |
| `kind` | `ui-kit`, `library`, `template`, `icons`, `wireframe` or `other`. |
| `author` | `name`, and `url` when there is one. |
| `source` | The original's `page`, and its `file` when there is one. |
| `licence` | `spdx` (an allowed licence, below) and `url` (the licence text). |
| `attribution` | What's shown with the kit and written into the file people add: the kit's title, its author, the licence and its link, and, when `modified`, that it was converted from the original. |
| `modified` | `true` when the file was converted or changed for Drawpane. |
| `file` | `url` (a path in the folder, or https), `format` (`penpot`), `sha256` and `bytes`: 25 MB at most. |
| `cover` | A PNG in the folder, 1390 x 724. |
| `tags`, `added` | Shown in the store; the date it was added (YYYY-MM-DD). |

### Licence rules

A kit hosted here must be under one of these licences: **MIT, Apache-2.0, CC-BY-4.0, CC-BY-SA-4.0, OFL-1.1, MPL-2.0, CC0-1.0**. Its attribution must name the kit and its author; for CC BY and CC BY-SA it must also name the licence and link it, and say the kit was converted from the original when it was. A cover rendered from a CC BY kit is an adaptation of it: credit it like the kit (the attribution covers both).

### Adding a kit

1. Make `kits/<id>/` with the kit's file (or an https URL to it), `kit.json` and a cover. Render the cover with Drawpane: import the file, and export its first page or a cover frame at 1390 x 724.
2. `npm ci && npm run index && npm run validate && npm test`.
3. Open a pull request. CI checks the kit (schema, licence, attribution, the file's sha256 and size, the cover) and that `index.json` is up to date.

## index.json

```jsonc
{
  "format": 1,
  "sources": [{ "provider": "drawpane", ... }, { "provider": "penpot", ... }],
  "kits": [
    {
      "id": "penpot-lucide-icons",
      "name": "Lucide Icons",
      "provider": "penpot",                 // or "drawpane"
      "kind": "icons",
      "categories": ["Icon set", "Libraries"],
      "description": "…",
      "author": { "name": "…" },             // or null
      "source": { "name": "Penpot's libraries and templates hub", "page": "https://penpot.app/…", "repository": "https://github.com/…" },
      "licence": null,                      // or { "text", "url" } (Penpot), { "spdx", "url" } (hosted here)
      "attribution": "…",                   // hosted here only
      "file": { "url": "https://penpot.github.io/…", "format": "penpot", "bytes": 1886654, "gitSha1": "…", "container": "zip" },  // or "sha256"; null when there's no file
      "cover": "https://…",                 // or a path relative to index.json, or null
      "published": "2024-02-13",
      "updated": "2025-06-06"
    }
  ]
}
```

URLs that aren't absolute are relative to `index.json`.
